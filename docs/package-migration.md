# Переход на новый пакет Eve Box

[English](package-migration.en.md) · [Установка](installation.md)

С `0.3.0-candidate.16` Eve Box использует пакет `io.github.ekkzy.evebox`.
Прежние выпуски, включая candidate.15 с именем Eve Box на экране, использовали
`io.github.ekkzy.softlumi`. Android считает их отдельными приложениями:
установка нового APK не обновляет старое приложение и не получает его данные.

1. В прежнем приложении экспортируй настройки в JSON и сохрани файл локально.
2. Установи новый APK и открой новое приложение из окна установки или мастера.
   У обеих версий на экране может быть имя Eve Box.
3. Открой сохранённый JSON в новом приложении, просмотри изменения и подтверди
   импорт. Проверь избранное, порядок приложений, фон и выбранный город.
4. Заново выбери источники рекомендаций и выдай нужные системные разрешения.
   Для кнопок пульта отключи прежнюю службу в специальных возможностях Android,
   затем включи службу нового приложения и выбери действия кнопок в Eve Box.
5. Если хочешь использовать новый Eve Box по кнопке Home, выбери его в настройках
   Android. На поддерживаемой прошивке Mi Box S 3 это также можно явно выбрать
   в [мастере установки](one-command-setup-ru.md). Проверь Home, Back, запуск
   приложений и возвращение фокуса.

JSON переносит поддерживаемые настройки, а не полную копию приложения.
История просмотра, погодный кеш, включённые источники рекомендаций, системные
разрешения и действия кнопок пульта в него не входят. Доступ к выбранному видео
заставки также нужно предоставить заново. Импорт показывает предварительный
просмотр и требует подтверждения; файл настроек остаётся личным файлом.

Старое приложение и его данные сохраняются. Установщик не удаляет его и
не включает службу специальных возможностей за тебя. До проверки новой версии
сохрани возможность вернуться к прежнему домашнему экрану. Удаление прежнего
приложения — отдельное ручное действие после проверки переноса; оно стирает
его локальные данные.

Сохрани прежний установочный комплект вместе с его журналами: проверять и
возвращать старые операции нужно через тот комплект, который их создал.
Новый мастер не принимает прежние планы и журналы. Если старая операция
не завершена, сначала разбери её результат; не удаляй журнал ради новой установки.

Последующие обновления `io.github.ekkzy.evebox` с тем же ключом подписи
устанавливаются поверх нового приложения. Смена ключа или очистка данных
не является способом исправить ошибку установки.
