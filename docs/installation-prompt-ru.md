# Промпт для установки из AI-комплекта

Скачай и распакуй [комплект закрытого предварительного релиза](https://github.com/ekkzy/softlumi/releases/tag/v0.3.0-candidate.14-setup.2), открой папку в ИИ-помощнике с локальным терминалом Windows и передай текст ниже. Для загрузки нужен доступ к приватному репозиторию. Пароль GitHub и токены передавать помощнику не нужно. [Инструкция и команды](ai-setup-ru.md) доступны отдельно.

```text
Помоги установить EVE-BOX (APK softlumi) из этой папки на явно выбранную мной Android TV.
Прочитай docs/ai-setup-ru.md, manifest.json, scripts/setup-tv.ps1 и scripts/setup-profiles/.
Сверь файлы, APK и сертификат с доверенными метаданными издателя, проверь SDK tools.
Выбери со мной устройство; передавай явные serial/model/fingerprint, без догадок по IP.
RSA, отладку и pairing выполняю я; пароли, токены и старые секреты не читай.
Создай Plan; по умолчанию generic-install-only, без смены HOME и отключений.
Профиль и приложения выбирай только по моему запросу; не угадывай и не меняй профиль.
Покажи точный план и SHA-256, дождись моего согласия, затем Apply с новым журналом.
Сохрани данные, избранное, remap-службы старого лаунчера, заставку и таймеры сна.
Не отключай пакет старого remapper; stock Google Home — только по одобренному профилю.
Не делай uninstall/reset/root/clear/downgrade и не обходи конфликты журнала.
После Apply выполни Inspect; попроси меня проверить Home/Back и нужные кнопки пульта.
При неизвестном результате установки остановись: Inspect не разрешает автоматический retry.
Restore выполняй по инструкции и подходящему журналу; APK и данные сохраняются.
Отчитайся о выполненном, ошибках и непроверенном; дай пути к журналу и команду возврата.
Устройства, аккаунты, историю, настройки и логи не публикуй и в облако не отправляй.
```
