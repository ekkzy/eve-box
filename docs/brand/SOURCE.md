28 октября 2026 для доработки. Для этих материалов не назначается новая
сторонняя лицензия; исходный архив сохранён отдельно без изменений.

- `EVE-Box-brand-preview-kit.zip`: SHA-256 `2c26274bc88810f107715c69ba525f9cd0dd2703f152f489aa18400fe377cf48`.
- `7130.jpg`: SHA-256 `3c39ee52f6412ba7010dc7f32e8a29c781ea8fdd28dfee236cfd806cb00cd268`.
- Векторные версии доработаны из SVG этого архива. Сведения о шрифте и его
  лицензии находятся в комплекте векторных материалов.
- Рекламная иллюстрация отредактирована встроенным imagegen. Промпты сохранены
  в рабочем каталоге, включая финальную замену фона и выбранные автором подписи.
- Основа экрана ТВ сохранена в `reference/home-landscape.png`. Это прежний
  снимок `docs/images/home-landscape.png` из публикационной копии проекта:

  Изображение не содержит личной истории просмотра и не заменяется при
  обновлении текущей галереи.
