# Eve Box — финальный брендкит

Название проекта: **Eve Box**. В словесном знаке используется написание
**EVE-Box** из исходного брендкита. Основной знак — буква E из трёх капсул
с укороченной средней перекладиной и тёплым персиково-сиреневым акцентом.

## Что использовать

- `branding/eve-box-icon.svg` — основной векторный исходник иконки с орбитальным фоном.
- PNG иконки — готовые растровые размеры; SVG сохраняет качество при масштабировании.
- Прозрачный словесный знак — для страниц и изображений; одноцветный — когда цвет не подходит.
- TV banner — для представления приложения на Android TV.
- Social preview и README hero — для оформления страницы проекта.
- `promo/eve-box-promo.png` — исправленная рекламная иллюстрация из переданного JPG.
- `reference/home-landscape.png` — отдельный неизменённый скриншот реального интерфейса с демоданными.

У знака сохраняют пропорции, интервалы и фирменный акцент. Его не растягивают
по одной оси и не добавляют новый контур или сильное свечение. На небольших
размерах используют отдельную иконку, а не всю надпись. Вокруг словесного знака
оставляют свободное место не меньше толщины его перекладины.

## Текст на промокартинке

Выбранные автором подписи: «Очистка от мусора», «Полная адаптация для РФ»,
«Кратное ускорение», «Менее 150 МБ RAM». На изображении нет сносок,
поясняющих подписей и дополнительных вариантов логотипа.

Промокартинка создана по реальному интерфейсу с космическим фоном.
Отдельный исходный снимок интерфейса — `reference/home-landscape.png`.

В `0.3.0-candidate.15` PNG иконки 512 × 512 и TV banner 320 × 180
используются в приложении без изменения изображений. Сам архив брендкита
содержит графику и не устанавливает приложение.
