# Установка

[English](installation.en.md) · [На главную](../README.md)

Приложение на приставке называется **Eve Box**: `0.3.0-candidate.16`, code 37.
Пакет — `io.github.ekkzy.evebox`. При переходе с прежнего пакета приложение
устанавливается отдельно; настройки и системные разрешения автоматически
не переносятся. [Инструкция по переходу](package-migration.md).

Нужны Android TV 8.0+ и пульт с D-pad. Выбор домашнего экрана зависит от прошивки.
Файлы доступны в
[предварительном выпуске candidate.16-setup.1](https://github.com/ekkzy/eve-box/releases/tag/v0.3.0-candidate.16-setup.1).

## Выбери способ

| Способ | Что нужно | HOME и приложения |
| --- | --- | --- |
| [APK вручную или через ADB](#apk-вручную-или-через-adb) | APK; для команды установки — ADB | Автоматически не меняются |
| [Через ИИ-помощника](ai-setup-ru.md) | Тот же комплект Eve Box, ADB и помощник с локальным терминалом | Только по подтверждённому плану и точному профилю |
| [Windows: одна команда](one-command-setup-ru.md) | Комплект Eve Box и ADB; ИИ, Java и Build-Tools не нужны | Только после выбора и подтверждения, на точной прошивке Mi Box S 3 |

Для установки с ИИ используется тот же архив и мастер; Java и SDK Build-Tools не нужны.

Если у тебя уже установлена предыдущая версия, сначала экспортируй её настройки
в JSON. Установи новую, открой файл в ней и проверь изменения перед импортом.
Старое приложение и его данные остаются на месте. Home, службу кнопок пульта,
разрешения и источники рекомендаций выбери заново; подробности — в
[инструкции по переходу](package-migration.md).

Последующие обновления внутри пакета `io.github.ekkzy.evebox` устанавливай
без удаления приложения. Они требуют того же ключа подписи и сохраняют его
данные. История просмотра других приложений через JSON не переносится.

## APK вручную или через ADB

Скачай [Eve-Box-0.3.0-candidate.16.apk](https://github.com/ekkzy/eve-box/releases/download/v0.3.0-candidate.16-setup.1/Eve-Box-0.3.0-candidate.16.apk)
и сверь SHA-256 с
[SHA256SUMS.txt](https://github.com/ekkzy/eve-box/releases/download/v0.3.0-candidate.16-setup.1/SHA256SUMS.txt)
из того же доверенного выпуска. В PowerShell хеш файла показывает команда:

```powershell
Get-FileHash .\Eve-Box-0.3.0-candidate.16.apk -Algorithm SHA256
```

Для установки без компьютера:

1. Передай APK на приставку и открой его файловым менеджером.
2. Если Android попросит, разреши этому файловому менеджеру установку приложений.
3. Установи APK и открой Eve Box из списка приложений.

Если ADB уже настроен, из папки с APK можно выполнить:

```powershell
adb devices -l
adb -s SERIAL install -r --user 0 Eve-Box-0.3.0-candidate.16.apk
```

Замени `SERIAL` на адресат, который ты проверил в списке. Для сетевого
подключения используй IP и порт своей приставки, например:

```powershell
adb connect 192.168.1.42:5555
```

Адрес — пример. Включение отладки, подтверждение подключения на ТВ и сопряжение
по коду, если оно требуется прошивкой, выполняет владелец. Подробности — в
[документации ADB](https://developer.android.com/tools/adb).

Ручная команда сохраняет данные уже установленного пакета `io.github.ekkzy.evebox`.
При переходе с прежнего пакета она устанавливает отдельное приложение.
Команда не создаёт журнал возврата, не назначает HOME и не отключает пакеты. При ошибке подписи или версии
разбери причину; не удаляй приложение и не очищай данные ради обхода ошибки.

## HOME и необязательная очистка

После обычной установки можно выбрать Eve Box домашним экраном в системных
настройках Android, если прошивка предоставляет такой выбор. Сохрани доступ
к прежнему лаунчеру. Для перехода с журналом используй общий комплект Eve Box.

Мастер предлагает автоматический переход HOME и отключение приложений
только при точном совпадении с
[профилем Mi Box S 3](../scripts/setup-profiles/mi-box-s3-android14.json):
модель `MiTV-AFMU0`, API 34 и указанный в профиле build fingerprint Xiaomi.
Названия устройства или версии Android недостаточно. На другой прошивке
доступна только установка, без автоматической смены HOME и отключений.

Все дополнительные действия изначально выключены. Отключение Google TV Home
требует выбранного перехода HOME. Необязательные приложения выбираются отдельно.
«Очистка» означает отключение выбранных пакетов для пользователя Android 0,
без удаления их данных. Это не обещание убрать всю рекламу или телеметрию.
Уже отключённые пакеты сохраняют точное исходное состояние.

## Проверка и возврат

Мастер сохраняет план и журнал локально. `Inspect` только проверяет состояние;
`Restore` возвращает записанные изменения HOME и пакетов, когда состояние
по-прежнему допускает безопасный возврат. Установленный APK и данные остаются.
Инструкции: [Windows-мастер](one-command-setup-ru.md#проверка-и-возврат),
[помощь ИИ](ai-setup-ru.md).

При потере связи результат команды может быть неизвестен. Сохрани журнал,
проверь состояние и не запускай установку повторно вслепую. Журнал не является
резервной копией старого APK. Полный проход нового комплекта на физической
Mi Box S 3 с заводской конфигурацией ещё не подтверждён; проверки на эмуляторе
не заменяют его.

После установки проверь физическую кнопку Home, Back, запуск приложений
и избранное. Установщики не настраивают службы пульта, специальные возможности,
CEC, заставку и таймеры сна.

## Первый запуск и перенос настроек

Добавь избранное, выбери формат карточек и фон. Погода и рекомендации выключены
по умолчанию. Для погоды выбери город; для рекомендаций включи функцию и нужные
приложения. Доступ к телевизионным карточкам запрашивается отдельно у Android,
если прошивка предоставляет разрешение.

Экспорт настроек сохраняется в JSON; перед импортом есть просмотр изменений.
Файл может содержать избранное, подписи приложений и город. Включённые приложения
рекомендаций и системные разрешения не переносятся: выбери их заново на другом
устройстве. Планы, журналы и личные резервные копии не публикуй.

[Брендкит Eve Box](https://github.com/ekkzy/eve-box/releases/download/v0.3.0-candidate.16-setup.1/EVE-BOX-brand-kit.zip)
содержит графические материалы, а не установщик. Для сборки из исходников см.
[инструкцию разработчика](building.md).
