# Установка

[English](installation.en.md) · [На главную](../README.md)

Нужен телевизор или приставка с Android TV 8.0+ и пульт с D-pad.
Телефоны и сенсорное управление не поддерживаются. Возможности выбора
домашнего экрана и доступа к карточкам зависят от прошивки.

## APK

Подписанный APK доступен участникам закрытого репозитория в
[комплекте установки](ai-setup-ru.md). Публичного стабильного релиза пока нет.
Можно также [собрать приложение](building.md). Не устанавливай сборку,
происхождение которой неизвестно.

1. Передай APK на своё устройство и открой его файловым менеджером.
2. При необходимости разреши установку из этого источника в настройках Android.
3. Установи приложение и запусти softlumi из списка приложений.

Обновление поверх существующей установки требует того же package и ключа
подписи. Не удаляй приложение ради обхода ошибки подписи: удаление стирает
локальные настройки. Debug-сборка использует отдельный package с суффиксом
`.debug` и может стоять рядом с основной.

## Первый запуск

Добавь любимые приложения, выбери формат карточек и фон. Погода и рекомендации
выключены по умолчанию. Для погоды выбери город; для рекомендаций включи функцию
и нужные приложения. Доступ к телевизионным карточкам запрашивается отдельно
через системное разрешение, если прошивка его предоставляет.

Установка APK не меняет HOME, службы пульта и настройки сна. Если хочешь
использовать softlumi как домашний экран, выбери его в системных настройках
приложения по умолчанию, если такой выбор доступен. Сохрани доступ к прежнему
домашнему экрану. На некоторых прошивках назначение HOME ограничено; для одной
прошивки Mi Box S 3 предусмотрен отдельный экспериментальный режим в
[комплекте установки](ai-setup-ru.md). Не переноси его отключения на другие модели.

Переназначение двух поддерживаемых кнопок Xiaomi — отдельная необязательная
функция. Она требует включения в softlumi и ручного разрешения в специальных
возможностях Android. Для обычной работы лаунчера это разрешение не нужно.

## Перенос настроек

Экспортируй JSON через настройки softlumi и сохрани его в выбранное место.
Перед импортом приложение показывает предварительный просмотр. Файл может
содержать избранное, подписи приложений и выбранный город — не публикуй его
без проверки. Включённые приложения рекомендаций и системные разрешения
не переносятся: выбери их заново на новом устройстве.
