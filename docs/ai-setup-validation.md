# Проверка комплекта установки

Комплект `v0.3.0-candidate.13-setup.1` предназначен для предварительного
использования участниками закрытого репозитория. Результаты проверки установщика
и приложения относятся к разным сценариям.

## Приложение в архиве

Подписанный APK `0.3.0-candidate.13`, versionCode 34:

- package: `io.github.ekkzy.softlumi`;
- SHA-256: `70d1bb14cadf17ed826885a3e855c7b015092d003c020c72fb7b8c6dd811a18f`;
- SHA-256 сертификата: `0774ab7eed2656fcd295934cefe672e89e9bbb8e99f3fb4febc40d6f646d96c6`.

27 октября 2026 года эта сборка была установлена и сверена по хешу на
Xiaomi Mi Box S 3 / MiTV-AFMU0, Android 14. Проверены Home, управление приложениями,
возврат и фокус, сохранение восьми избранных приложений и порядка. Состояние
служб и настройки сна сохранены. Размер интерфейса на приставке — 1920 × 1080;
выход HDMI 4K не означает окно приложения 4K.

Изменения приложения до упаковки прошли 283 JVM-теста и обе проверки lint
(0 ошибок, 19 существующих предупреждений), 15 native-сценариев на собственном
эмуляторе API 34 с окном 3840 × 2160 и font scale 1.0. После изменения номера
версии отдельно проверены сборка, обновлённый screenshot guard и подписанный APK.
DEX и assets финальной версии совпали с проверенным кандидатом; новый установщик
не меняет APK. Эти проверки не являются тестом полного отключения приложений
на исходной заводской конфигурации Xiaomi.

## Установщик

На собственном эмуляторе Android API 34 (окно 3840 × 2160, font scale 1.0)
проверен путь с настоящими Android SDK tools и подписанным APK:

1. `Plan` прочитал исходные состояния без изменений Android.
2. `Apply` установил APK, сверил его фактический SHA-256 и открыл приложение.
3. Тестовый профиль временно отключил синтетический пакет и прежний HOME.
4. `Inspect` подтвердил результат; команда Home открыла softlumi.
5. `Restore` вернул оба пакета из состояния 3 в исходное 0 и прежний Nexus HOME.
   После завершения перехода команда Home открыла Nexus. Настройки специальных
   возможностей, сна и полный список отключённых пакетов совпали с исходными.

Для этого использована копия того же backend с искусственным профилем точного
эмулятора. Этот профиль в комплект не входит и не считается проверкой Xiaomi.
Отдельно прошла базовая установка без изменения HOME и пакетов.

На Mi Box S 3 / MiTV-AFMU0, Android 14, выполнен только режим `Plan` финального
профиля: проверены точное совпадение прошивки, доступность выбранных пакетов и
метаданные установленного приложения. Команды изменения на приставку не отправлялись.

Офлайн-матрица завершена: **33/33 сценария** в Windows PowerShell
5.1.26100.9711 и **33/33** в PowerShell 7.6.5, всего **66 PASS**, 0 FAIL.
Это выполнение реального backend с изолированными заменами SDK-инструментов,
без доступа к настоящему ADB. Покрыты неверные APK/подпись/адресат/профиль,
изменение или истечение плана, обновление уже выбранного HOME, точное сохранение
состояний 0–4, частично выполненные команды, потеря ответа после commit,
сторонние изменения, переход на третий HOME, перенос журнала PS7 → PS5.1,
повторный журнал, метаданные TV APK, аргументы и тайм-ауты.

У каждого дочернего вызова backend был отдельный предел 50 секунд.
Максимумы в двух полных прогонах — 27.8 и
27.5 секунды. Ранние неуспешные прогоны сохранены
как диагностика; они не включены в число PASS. Финальные отчёты и native-сценарий
относятся к одной версии backend.

## Пределы

Профиль `mi-box-s3-android14` сопоставляет точные модель, API и build fingerprint.
Его список отключений не переносится автоматически на другие прошивки.
Полный проход нового установщика на свежей физической Xiaomi ещё не подтверждён.
Проверки с искусственными ответами ADB и эмулятор не заменяют такой проход.

Не проверялись все версии Windows, TV-прошивки, OTA-обновление и длительная
работа после reboot. Установщик не обещает экономию RAM, рост FPS, отключение
всей телеметрии или всех рекламных компонентов. Сохранённое значение тайм-аута
не подтверждает фактическое засыпание через три часа.

При неизвестном результате установки APK автоматический повтор запрещён:
`Inspect` показывает наблюдаемое состояние, но не доказывает завершение всех
сессий PackageManager. `Restore` не возвращает прежнюю версию APK и не удаляет
данные. При конфликте с изменениями пользователя требуется разбор состояния.

В одном предварительном офлайн-прогоне Windows отказала в атомарной замене
файла журнала. Повтор того же сценария без изменения backend прошёл; причина
единичного отказа не установлена. Запись журнала обязательна до команды изменения:
при ошибке нужно сохранить журнал и проверить состояние через `Inspect`.
