# Проверка комплекта установки

Комплект `v0.3.0-candidate.14-setup.2` содержит приложение, которым автор
пользуется на своей Mi Box S 3. Профиль основан на его рабочей конфигурации.
Ниже отдельно описаны проверки приложения и нового установщика.

## Приложение в архиве

Подписанный APK `0.3.0-candidate.14`, versionCode 35:

- package: `io.github.ekkzy.softlumi`;
- SHA-256: `9f6787ba2badeb63c067eabc1153e2545773cadd9adfe024c5e1eaa6a5f556a6`;
- SHA-256 сертификата: `0774ab7eed2656fcd295934cefe672e89e9bbb8e99f3fb4febc40d6f646d96c6`.

В этой версии белый ореол часов, даты и погоды на светлом фоне заменён
нейтральной тёмной тенью. Тёмное оформление и геометрия интерфейса сохранены.

27 октября 2026 года прошли debug/release сборки, компиляция Android-тестов
и оба lint: 0 ошибок, по 19 существующих предупреждений. На собственном
эмуляторе API 34 с реальным окном 3840 × 2160 и font scale 1.0 прошли шесть
адресных native-тестов: тень в отрисованных пикселях, повторное обновление
погоды, верхний блок в трёх сочетаниях палитры/фона и три тёмных снимка для
галереи. Светлые контрольные снимки просмотрены отдельно и в галерею не входят.
Сборка сохранила прежний сертификат; все 74 payload-файла подписанного APK
побайтово совпали с неподписанным результатом сборки.

Этот APK установлен на Xiaomi Mi Box S 3 / MiTV-AFMU0, Android 14 и сверен
по SHA-256 непосредственно на устройстве. Проверены Home, перемещение и возврат
фокуса, сохранение восьми избранных приложений и порядка. Список отключённых
пакетов, службы пульта и настройки сна остались прежними. Размер интерфейса
приставки — 1920 × 1080; выход HDMI 4K не означает окно приложения 4K.
В текущем процессе не найдено FATAL/ANR. Новый замер CPU/RAM для этой небольшой
правки цвета не выполнялся; прежние измерения сохраняют свои версии и условия.

## Установщики в setup.2

Оба комплекта используют одну финальную версию Plan/Apply/Inspect/Restore.
AI-комплект проверяет APK настоящими SDK-инструментами; мастер одной команды
принимает только точные байты закреплённого выпуска без Java и Build-Tools
на компьютере пользователя. Подпись, пакет и метаданные APK проверены перед
упаковкой. Данные проверки относятся к неизменным исполняемым файлам комплектов;
при публикации обновлены инструкции и manifest.

28 октября 2026 финальные проверки в Windows PowerShell 5.1 и PowerShell 7:

| Проверка | Результат |
| --- | --- |
| Мастер и backend, управляемые ответы ADB | 20 сценариев в каждом runtime, всего 40 PASS |
| Атомарная запись журнала, реальные файлы и блокировки | 7 сценариев в каждом runtime, всего 14 PASS |
| Затронутые сценарии прежнего SDK-режима | 3 сценария в каждом runtime, всего 6 PASS |

Итого 60 успешных запусков на финальных исходниках. Сверены хеши входных файлов
до и после выполнения. Проверены несовместимая прошивка, подмена APK/плана,
отмена и EOF, несколько устройств, отсутствие авторизации, полный Apply/Inspect/
Restore, изменение журнала, неизвестный результат установки и конкурирующие мастера.
Полная прежняя SDK-матрица 33×2=66 PASS выполнена до доработки атомарного writer;
она не заменяет перечисленные проверки финальной версии.

Настоящий `install.cmd` из комплекта прошёл Preview → Install → Inspect → Restore
в Windows PowerShell 5.1 на собственном Android API34 эмуляторе с окном
3840×2160 и font scale1.0. Проверялась установка точного APK35 поверх APK35,
в режиме generic install-only. Хеш установленного APK совпал, приложение
открылось. HOME, отключённые пакеты, accessibility и таймеры сохранились.
Эмулятор остановлен после проверки. Отдельно подтверждён отказ второго мастера,
когда первый удерживает подтверждение для того же устройства.

В промежуточном PS7-прогоне атомарная замена журнала отказала при Restore;
причина исходного отказа неизвестна. Финальная версия допускает ограниченные
повторы только для определённых Windows-ошибок и при точном совпадении старых
и ожидаемых новых байтов. Постоянная блокировка и неизвестное состояние приводят
к остановке; старый файл сохраняется. Повторы команд ADB не добавлены.
Это проверено отдельными тестами настоящих файловых блокировок.

На физической Mi Box S 3 ранее выполнялся read-only Plan профиля и установка
самого APK35. Полный проход очистки новой обёрткой на свежей физической Xiaomi
не выполнялся. Проверка эмулятора в generic mode не подтверждает этот сценарий.

## Пределы

Профиль `mi-box-s3-android14` требует точного совпадения модели, API и build
fingerprint. Он основан на рабочей конфигурации автора; список отключений
не переносится автоматически на другую прошивку. На других устройствах
доступна установка без очистки и автоматического назначения Home.

Не проверялись все версии Windows, TV-прошивки, OTA-обновление и длительная
работа после reboot. Новых сравнений RAM/CPU/FPS в этом этапе не было.
Сохранение тайм-аута не подтверждает наблюдением засыпание через три часа.

При неизвестном результате установки APK автоматический повтор запрещён:
`Inspect` показывает наблюдаемое состояние, но не доказывает завершение всех
сессий PackageManager. `Restore` возвращает записанные состояния пакетов и Home,
сохраняет установленный APK и данные; прежнюю версию APK он не возвращает.
Конфликт с последующими ручными изменениями требует отдельного разбора.
