# Eve Box: установка одной командой

[Все способы установки](https://github.com/ekkzy/eve-box/blob/main/docs/installation.md)

Windows-мастер устанавливает лаунчер через ADB, показывает план и выполняет
его после твоего подтверждения. ИИ, Java, Android Studio и SDK Build-Tools
для этого комплекта не нужны.

Скачай [Eve-Box-setup-candidate.15.zip](https://github.com/ekkzy/eve-box/releases/download/v0.3.0-candidate.15-setup.1/Eve-Box-setup-candidate.15.zip)
из [выпуска candidate.15-setup.1](https://github.com/ekkzy/eve-box/releases/tag/v0.3.0-candidate.15-setup.1).
Приложение этого выпуска — **Eve Box 0.3.0-candidate.15 / code 36**.
Пакет `io.github.ekkzy.softlumi` и ключ подписи сохранены для совместимого
обновления с прежними данными.

## Запуск

1. Полностью распакуй ZIP в отдельную локальную папку, доступную для записи.
2. Подготовь [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools).
   Если `adb` уже доступен в терминале, устанавливать его заново не нужно.
   Можно положить распакованную папку `platform-tools` рядом с `install.cmd`.
3. Включи отладку на приставке. Для сетевого подключения компьютер и ТВ должны
   видеть друг друга в локальной сети. Разреши подключение на экране телевизора.
4. Открой терминал в папке комплекта и выполни:

```powershell
.\install.cmd
```

`install.cmd` использует Windows PowerShell 5.1. Мастер не требует прав
администратора и не меняет постоянную политику выполнения PowerShell.

Если подключено несколько устройств, мастер предложит явно выбрать одно.
Если устройств нет — спросит IPv4-адрес и порт. Адрес можно указать сразу:

```powershell
.\install.cmd -Serial 192.168.1.42:5555
```

Это пример адреса. IP смотри в сетевых настройках своей приставки, а порт —
в настройках отладки. Он не обязательно равен 5555. Если прошивка требует
сопряжение с кодом, сначала выполни
[сопряжение ADB](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi).
Мастер не сканирует сеть и не обходит авторизацию на ТВ. При `unauthorized`
или `offline` он останавливается без установки.

При необходимости укажи свой ADB:

```powershell
.\install.cmd -AdbPath "C:\Android\platform-tools\adb.exe"
```

## Выбор действий

Мастер проверит модель и прошивку. Автоматический переход HOME и очистка
доступны только для точного
[профиля Mi Box S 3](../scripts/setup-profiles/mi-box-s3-android14.json):
`MiTV-AFMU0`, API 34 и build fingerprint из профиля. На другой модели или сборке
доступна только установка APK; HOME и остальные приложения не меняются.

В точном профиле можно отдельно выбрать:

- назначить Eve Box домашним экраном HOME;
- отключить Google TV Home вместе с переходом HOME;
- отключить установленные необязательные приложения из списка: Netflix,
  Prime Video, YouTube Music, Google Play Games, Mi Music, Xiaomi analytics
  и Google Feedback.

Все варианты изначально выключены. Необязательные приложения выбираются
номерами; ответ «все» / `all` выбирает весь показанный список. Отключённые
приложения не запускаются у пользователя Android 0, но их данные не удаляются.
Уже отключённые пакеты сохраняют точное исходное состояние. Отключение Xiaomi
analytics не отключает телеметрию других приложений.

Перед применением ты увидишь приставку, версию APK, прежний и запрошенный HOME
и конкретные пакеты. Введи `УСТАНОВИТЬ` или `YES`, чтобы применить именно этот
план. Пустой или другой ответ отменяет установку. Для предварительного просмотра
без применения:

```powershell
.\install.cmd -PreviewOnly
```

Сначала устанавливается APK, проверяются его версия и SHA-256 на устройстве,
затем открывается лаунчер и только после этого выполняются выбранные изменения.
Службы пульта, accessibility, учётные записи, CEC, заставка и таймеры сна
не настраиваются. Существующий перехватчик HOME может помешать переходу;
комплект не отключает его автоматически.

В одной сессии Windows для одного адресата и ADB-порта работает только один
мастер, включая время подтверждения. Незавершённый журнал этого комплекта
блокирует новую установку до разбора состояния.

## Проверка и возврат

План и журнал сохраняются внутри `setup-private` в отдельной папке операции:
`setup-private/<идентификатор>/setup-journal.json`. После операции мастер
показывает точный путь. Сохрани комплект вместе с этой папкой.

```powershell
.\install.cmd -Mode Inspect
.\install.cmd -Mode Restore
```

Каждая команда спросит путь к сохранённому журналу. Его можно передать явно
через `-JournalPath`. `Inspect` только проверяет фактическое состояние.
`Restore` показывает приставку и возвращаемые изменения; для выполнения нужно
ввести `ВЕРНУТЬ` или `RESTORE`. Если журнал изменился после просмотра,
возврат не начнётся.

`Restore` возвращает только записанные изменения HOME и пакетов, включая
частично выполненный план. APK и данные приложения остаются. Возврат требует
того же адресата, прошивки и неизменного ADB, доступен для журналов не старше
14 дней и отказывает при конфликте с последующими изменениями. Журнал не
является копией старого APK или резервной копией всей системы.

При тайм-ауте или потере связи сохрани журнал и запусти `Inspect`. Если результат
установки неизвестен, даже видимые версия и хеш APK не разрешают автоматический
повтор. `Restore` тоже откажет: сначала нужно отдельно проверить завершение
установочной сессии Android. Не удаляй приложение и журнал ради обхода ошибки.
При частичном возврате пакетов и конфликте HOME часть собственных изменений
уже может быть отменена — ориентируйся на результат проверки и журнал.

После установки проверь физическую кнопку Home, Back, запуск приложений
и избранное. Полный проход нового комплекта на физической Mi Box S 3
с заводской конфигурацией ещё не подтверждён.

## Проверенный APK и приватность

Мастер принимает только точные байты APK36, закреплённые в коде установщика.
Подпись и метаданные этого файла проверяются при подготовке выпуска;
на компьютере пользователя проверяются размер и встроенный SHA-256.
Другой APK или изменённый профиль не будут приняты. Скачивай комплект
из доверенного выпуска и сверяй
[SHA256SUMS.txt](https://github.com/ekkzy/eve-box/releases/download/v0.3.0-candidate.15-setup.1/SHA256SUMS.txt):
проверка APK не защищает от подмены самого установщика.

Планы и журналы содержат адресат, прошивку, HOME и состояния пакетов.
Храни `setup-private` локально и не загружай её на GitHub.
Этот же комплект можно пройти [с ИИ-помощником](ai-setup-ru.md).
[Ручной SDK-режим](advanced-setup.md) оставлен для опытных пользователей.
