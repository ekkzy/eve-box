# EVE-BOX: установка с ИИ-помощником

[Все способы установки](https://github.com/ekkzy/softlumi/blob/main/docs/installation.md) · [English](ai-setup.md)

Помощник проверит комплект, поможет подключить приставку и запустить
тот же Windows-мастер, что используется для
[установки одной командой](one-command-setup-ru.md). Нужен помощник с доступом
к локальному терминалу Windows. Обычный чат может объяснить шаги, но выполнить
команду на компьютере нужно будет тебе.

## Как начать

1. Скачай [EVE-BOX-setup-candidate.14.zip](https://github.com/ekkzy/softlumi/releases/download/v0.3.0-candidate.14-setup.3/EVE-BOX-setup-candidate.14.zip)
   из [выпуска setup.3](https://github.com/ekkzy/softlumi/releases/tag/v0.3.0-candidate.14-setup.3)
   и полностью распакуй в отдельную локальную папку, доступную для записи.
2. Открой эту папку в помощнике и передай ему
   [готовый запрос](installation-prompt-ru.md).
3. Включи отладку на приставке и разреши подключение на экране ТВ;
   помощник объяснит сопряжение по коду, если оно требуется.
   Выбери действия в мастере, проверь показанные устройство и план.
   Для применения введи `УСТАНОВИТЬ` или `YES`. Пустой ответ отменяет установку.

Из Android-инструментов нужен только
[Platform-Tools с ADB](https://developer.android.com/tools/releases/platform-tools).
Помощник проверит, установлен ли он, и при необходимости поможет подготовить
официальную версию. Java, Android Studio и SDK Build-Tools не нужны.
Мастер запускается из папки комплекта:

```powershell
.\install.cmd
```

Вводи ответы сам или передавай их помощнику по одному. Подтверждение установки
даётся только после просмотра текущего плана; заранее подставлять его нельзя.
Если терминал помощника не поддерживает диалог с мастером, он подготовит
команду для твоего терминала.

## Что изменится

По умолчанию мастер только устанавливает и открывает приложение.
В этом выпуске оно ещё называется **softlumi 0.3.0-candidate.14 / code 35**;
package и подпись прежние. Совместимое обновление сохраняет данные.

Назначение домашнего экрана HOME и отключение приложений выбираются отдельно.
Они доступны только при точном совпадении модели, Android API и прошивки
с [профилем Mi Box S 3](../scripts/setup-profiles/mi-box-s3-android14.json).
На другой прошивке доступна только установка APK. Отключение сохраняет данные
приложений; службы пульта, заставка и таймеры сна не настраиваются.

Мастер принимает только закреплённый APK выпуска. Подпись этого файла проверена
при подготовке комплекта; на твоём компьютере проверяются его размер и SHA-256.
Помощник должен сверить источник и комплект с
[SHA256SUMS.txt](https://github.com/ekkzy/softlumi/releases/download/v0.3.0-candidate.14-setup.3/SHA256SUMS.txt)
и `manifest.json`. Совпадение хеша не делает неизвестный источник доверенным.

## Проверка и возврат

После установки проверь Home, Back, запуск приложений и избранное.
Полный проход мастера на физической Mi Box S 3 с заводской конфигурацией
ещё не подтверждён.

Сохрани комплект вместе с папкой `setup-private`: в ней план и журнал операции.
`Inspect` проверяет состояние, `Restore` возвращает записанные изменения HOME
и пакетов после твоего подтверждения. Установленный APK и данные остаются.
Возврат требует того же адресата, прошивки и ADB, журнала не старше 14 дней
и отсутствия конфликтующих изменений.

При потере связи сначала проверь журнал через `Inspect`. Если результат
установки неизвестен, автоматический повтор и `Restore` запрещены до разбора
установочной сессии Android. Не удаляй приложение, его данные или журнал
ради обхода ошибки. [Команды проверки и возврата](one-command-setup-ru.md#проверка-и-возврат).

Журналы содержат сведения о приставке и её настройках. Храни их локально;
не публикуй и не прикладывай к облачному чату. Пароли и токены помощнику не нужны.
