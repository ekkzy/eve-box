# EVE-BOX — установка через ИИ

[Скачать комплект для Windows](https://github.com/ekkzy/softlumi/releases/tag/v0.3.0-candidate.14-setup.2)
· [Инструкция](../../docs/ai-setup-ru.md)
· [English guide](../../docs/ai-setup.md)
· [Готовый запрос](../../docs/installation-prompt-ru.md)

Комплект содержит подписанный APK `0.3.0-candidate.14` / code 35, скрипты
PowerShell и профиль одной прошивки Xiaomi Mi Box S 3. Распакуйте ZIP и передайте
запрос помощнику с доступом к терминалу на вашем компьютере. Первая авторизация
отладки выполняется владельцем на приставке. Затем помощник показывает план
и применяет его только после согласия.

Это предварительный выпуск в закрытом репозитории. Доступ к архиву имеют
участники репозитория; GitHub-токены не нужно вставлять в запрос для ИИ.
Существующая установка softlumi обновляется с сохранением данных.

По умолчанию системные приложения не отключаются и HOME не меняется.
Дополнительный профиль требует точного совпадения модели и прошивки.
Необязательные приложения выбираются отдельно. Откат возвращает записанные
состояния пакетов и HOME, сохраняя установленную версию APK и данные приложения.

Профиль Mi Box S 3 основан на конфигурации, которой владелец проекта пользуется
на своей приставке. Он привязан к конкретной прошивке; не меняйте профиль ради
обхода проверки совместимости. [Условия и результаты проверок установщика](../../docs/ai-setup-validation.md).

[manifest.json](manifest.json) содержит версию, SHA-256 APK, отпечаток сертификата
и список файлов комплекта. Само совпадение хеша не подтверждает доверие к
неизвестному источнику: скачивайте комплект из этого репозитория.

Для установки без ИИ есть отдельный [мастер одной команды](../../docs/one-command-setup-ru.md).
Название установленного APK пока softlumi; пакет и сертификат сохранены.
