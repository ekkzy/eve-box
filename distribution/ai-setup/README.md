# Eve Box: установка с ИИ-помощником

Для установки с ИИ используется общий
[Eve-Box-setup-candidate.16.zip](https://github.com/ekkzy/eve-box/releases/download/v0.3.0-candidate.16-setup.1/Eve-Box-setup-candidate.16.zip)
и команда `install.cmd`. Отдельный AI-архив больше не нужен.

Распакуй ZIP, открой его папку в помощнике с локальным терминалом Windows
и передай [готовый запрос](../../docs/installation-prompt-ru.md).
Помощник проверит комплект и ADB, поможет с подключением и запуском мастера.
Выбор действий и подтверждение конкретного плана вводишь ты.
Нужны Windows и Platform-Tools с ADB; Java и SDK Build-Tools не требуются.

По умолчанию устанавливается и открывается Eve Box `0.3.0-candidate.16`
/ code 37 с пакетом `io.github.ekkzy.evebox`. Он устанавливается отдельно от прежнего пакета; для настроек нужен экспорт и импорт JSON. Смена HOME и отключение приложений — отдельный
выбор, доступный только для точной поддерживаемой прошивки Mi Box S 3.
Возврат по журналу восстанавливает записанные HOME и пакеты, сохраняя APK
и данные. Если результат установки неизвестен, сначала нужен разбор состояния.

мастера ещё не подтверждён. Папку `setup-private` с планами и журналами
храни локально и не публикуй.
