# Eve Box — установка

Распакуй комплект и открой терминал в его папке:

```powershell
.\install.cmd
```

Нужны Windows и ADB. Мастер предложит ввести IP или выбрать подключённую
приставку, настроить очистку и подтвердить итоговый план. Подробности —
[в инструкции](../../docs/one-command-setup-ru.md).

Очистка и назначение Home доступны для точной поддерживаемой прошивки
Mi Box S 3. На остальных устройствах мастер устанавливает APK без отключений.
Ненужные приложения выбираются явно; данные сохраняются, журнал нужен для возврата.

В комплекте проверенный APK Eve Box `0.3.0-candidate.16` / code37. Пакет — `io.github.ekkzy.evebox`. При переходе с прежнего пакета приложение устанавливается отдельно; настройки переносятся через JSON.
Java и Android SDK Build-Tools не нужны.

Для помощи ИИ открой эту папку в помощнике с локальным терминалом и отправь
[готовый запрос](../../docs/installation-prompt-ru.md). Используется тот же мастер;
дополнительные инструменты для проверки APK не требуются.
[English guide and prompt](../../docs/ai-setup.md).

[Переход с прежнего пакета](../../docs/package-migration.md). Старые журналы нужно открывать исходным комплектом установки.
